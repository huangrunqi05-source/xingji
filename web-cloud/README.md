# 行迹 · 私人探店本（Web）

手机 Safari 打开发布链接，用创建本站的 ChatGPT 账号登录，再通过分享菜单「添加到主屏幕」。Mac 直接用浏览器打开同一地址。

## 已实现

- 主动打卡、可选即时定位、手动填写店名地址和到访时间。
- 半星评分、文字、每次到访最多 6 张照片。上传时压缩并移除 EXIF/GPS/IPTC 元数据；失败保留编辑和重试入口。
- 到访历史、分店聚合、再次到访、按日期/评分/分类筛选、编辑和删除。
- 每个账号的记录和照片存入 D1/R2。API 全部校验身份和所有权，不接受客户端传入的 owner。
- 独立清单副本，预览后加入；导出含照片的 HTML 清单，通过手机分享菜单或文件发送。清单不含定位坐标、精确时间或完整历史，私人编辑不会更新副本。
- 全量导出 JSON（含照片数据，暂限 120 MB），删除全部数据；主屏幕图标和离线说明。

## 明确限制

- 不在锁屏或后台采集位置，不自动同步外卖订单。
- 保存和读取需要联网。无 iCloud 同步，无离线写入队列；保存失败时请保留页面重试。
- 首版部署为仅站点拥有者可访问。好友分享为导出文件，不是在线邀请；已发送文件不可撤销。CloudKit/账号邀请版尚未实现。
- 尚未配置高德 Web JS Key 及安全密钥时，内嵌地图/附近店铺搜索不能使用。手动记录及跳转高德官方搜索可用。
- 尚未完成真实 iPhone Safari 定位/系统分享、国内网络可达性及生产端跨设备实测。

## 高德配置

申请高德 Web 端（JS API）的 Key 和安全密钥，配置站点环境变量 `AMAP_JS_KEY`、`AMAP_SECURITY_CODE`，按高德控制台要求配置域名白名单，再重新发布。安全密钥只保存在服务器环境，通过固定白名单代理调用。浏览器定位保留 WGS84；只有在绘图和搜索时用 AMap.convertFrom 转换，搜索结果以 GCJ02 保存，避免二次转换。

## 开发

- Node >=22.13, npm；`npm run dev` 启动本地预览。
- 本地模拟登录为开发专用测试身份，不会进入生产包。
- `npx tsc --noEmit` 类型检查。
- D1 迁移由 `npm run db:generate` 生成；发布系统应用 `drizzle/` 迁移。
- Sites 身份在 `.openai/hosting.json`，环境值不能写入该文件。
- 原生 iOS 项目位于相邻 `Xingji` 文件夹，未被替换。
